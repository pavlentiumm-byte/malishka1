# Палитры ВКадре — 28 октября 2026

## Ориентиры

- Linear: официальное руководство предпочитает монохромное применение логотипа, спокойный ненасыщенный синий и свободное пространство вокруг элементов. Для ВКадре применён принцип нейтральной основы с умеренным акцентом, без копирования бренда. Источник: https://linear.app/brand
- Vercel Geist: отдельные роли для фонов, состояний hover/active, границ и основного/вторичного текста. Это полезнее набора случайных оттенков: одна палитра должна последовательно работать на всех экранах. Источник: https://vercel.com/geist/colors
- Notion: просмотрены главная и бренд-руководство как пример иерархии разделов и единообразия коммуникации. Точные HEX-значения из них не заимствовались. Источники: https://www.notion.com/ и https://notion.notion.site/Notion-Brand-Guidelines-db8fda2d1f0048bba1f4e547dfc48830

Популярность сервиса сама по себе не доказывает, что его цвета оптимальны для другой аудитории. Выбор для ВКадре — дизайнерская гипотеза, а не результат пользовательского исследования.

## Варианты

| Палитра | Светлый фон / текст | Тёмный фон / текст | Характер |
|---|---|---|---|
| Классика | #F6F6F4 / #252925 | #1B1F1B / #EEF1EC | Нейтральная, мягкий шалфей |
| Тёплый песок | #F7F4EE / #342D25 | #211E1A / #F4EDE2 | Молочный фон, кофейные оттенки |
| Холодный сланец | #F2F5F9 / #25364B | #18212C / #EDF2F9 | Серо-голубой фон, графит |

Для максимально нейтрального просмотра фотографий предпочтительна «Классика». Для более тёплого, редакционного ощущения стоит сравнить «Песок». «Сланец» подходит, если хочется более собранного инструментального интерфейса. Текущий выбор пользователя не изменяется автоматически.

## Реализация и проверка

Палитра независима от режима light/dark и хранится в существующих settings. Старые настройки получают palette=sage. Внешний вид переключается через CSS-переменные; компоненты и содержание одинаковые для честного сравнения. Радиокарточки доступны с клавиатуры. Иконка чатов получила цельный замкнутый контур с согласованными началом/концом кривой.

В WebKit проверены шесть комбинаций на 390 и 1280 px, применение настроек, отсутствие горизонтального переполнения основных экранов и восстановление выбора после настоящей перезагрузки. Расчёт контраста основного/вторичного текста к двум базовым фонам: минимум 4,88:1. Это проверка указанных пар, не заявление об аудите всех элементов на полное соответствие WCAG. Синтаксические/доменные проверки и git diff --check пройдены.
